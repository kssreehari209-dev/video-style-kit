# Sound effect map

Generated by `scripts/generate_sfx.py`. Re-run it after changing any parameter.

| File | Use it for | Suggested volume |
|------|-----------|------------------|
| `ocean_drone.wav` | Looping bed under the whole video | 0.20 to 0.30 |
| `sonar_ping.wav` | Sonar ripple rings expanding | 0.60 |
| `ui_check.wav` | Checkboxes and checkmarks | 0.70 |
| `ui_pop.wav` | Text boxes, brackets, labels appearing | 0.60 |
| `scan_typing.wav` | Prey receipt scrolling, scanning readouts | 0.50 |
| `thud.wav` | A scale comparison snapping on screen | 0.90 |
| `ui_alert.wav` | Red warnings ("NEVER PROVEN", "CANCEL") | 0.70 |

## Syncing in Remotion

Start each sound on the exact frame where its visual animation starts.

```tsx
import {Audio, Sequence, staticFile, useVideoConfig} from "remotion";

// Put the WAV files in the Remotion project's public/sfx/ folder.
const Sfx = ({file, frame, volume = 0.7}: {file: string; frame: number; volume?: number}) => (
  <Sequence from={frame}>
    <Audio src={staticFile(`sfx/${file}`)} volume={volume} />
  </Sequence>
);

// Looping bed for the whole video:
<Audio src={staticFile("sfx/ocean_drone.wav")} volume={0.25} loop />

// A pop on frame 90, a thud on frame 150:
<Sfx file="ui_pop.wav" frame={90} />
<Sfx file="thud.wav" frame={150} volume={0.9} />
```

Because the video uses hard cuts, put a sound on the cut frame itself, not before it.
